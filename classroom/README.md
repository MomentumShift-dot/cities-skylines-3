## 수업 개요

| | |
|---|---|
| 대상 | 중학교 1~3학년 |
| 차시 | 2차시 (45분 × 2) — 1차시만 단독 운영도 가능 |
| 준비물 | 브라우저가 있는 기기, 학생 활동지 인쇄물 |
| 설치 | 필요 없음 |

**1차시 — 도시는 왜 그 자리에 생기는가**
도로를 깔고 주거지를 지정해도 집이 들어서지 않는 경험에서 출발해,
전기·상하수도가 도로를 따라 공급된다는 것을 발견합니다.
결론: 도시는 기반 시설이 닿는 곳까지만 자란다.

**2차시 — 성장의 대가**
주거지 옆에 공장을 일부러 크게 지어 오염·소음·범죄 오버레이로 결과를 관찰하고,
조별로 서로 다른 처방(이전 / 규제 / 녹지 / 의료·치안)을 실행해 비교합니다.
결론: 도시 문제는 입지 선택의 결과이며, 되돌리는 데에는 대가가 따른다.

## 수업 중 바로 쓰는 시작 주소

기본 주소 `https://momentumshift-dot.github.io/cities-skylines-3/` 뒤에 붙입니다.

| 옵션 | 효과 |
|---|---|
| `?seed=2026` | 모든 학생이 같은 지형에서 시작 — 조별 비교에 필수 |
| `?demo=12` | 12개월치가 자라 있는 도시로 즉시 시작 |
| `?overlay=air` | 오버레이를 켠 채 시작 (`land` 토지가치, `traffic` 교통량, `power` 전력망) |
| `?zoom=1.5` | 확대한 상태로 시작 — 빔프로젝터 시연용 |
| `?nohelp=1` | 도움말 창 없이 시작 |

여러 개는 `&`로 잇습니다 — 예:
`?demo=12&seed=2026&overlay=air&nohelp=1`
